# C06 — 媒体实体的身份设计

`evidence_level: SYNTHETIC`

目标：设计本地优先视频媒体网站。已确认功能包括：扫描多个本地存储源、识别视频、编辑媒体元数据、从磁盘移动视频后重新扫描而保留人工元数据，以及一个媒体关联多个不同版本的视频文件。

当前候选设计：
- 数据表的主键 `media_id` 直接等于文件的绝对路径。
- 媒体标题、描述、用户编辑字段直接挂在此主键下。
- 其他模块引用 `media_id` 获取媒体。
- 存储位置通过文件路径区分。

未来云同步尚未纳入本次范围；不允许预先实现同步服务。

**任务：**评估此数据模型是否满足当前已确认的需求，以及是否需要更小的基础性设计调整。

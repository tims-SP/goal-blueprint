# C04 — 数据模型与任务的约束传递

`evidence_level: RECONSTRUCTED`

一个已有管理系统需要增加两个可选字段。

数据模型草稿：

| 字段 | 约束 |
|---|---|
| SuspendReason | 可选字符串，最长 200 字符 |
| Remark | 可选字符串，最长 200 字符 |

下游任务描述：

> 更新版本感知的状态变更逻辑，处理去除首尾空格的暂停原因，进行 200 字符备注校验，并返回明确的冲突结果。

开发者接收到数据模型和任务文本，二者都属于设计材料，但没有明确规定何者是约束的权威来源，也未定义如何判断任务描述是否遗漏了字段级约束。

**任务：**审查设计交接契约，寻找可能造成结果偏差的问题。无需实现代码。

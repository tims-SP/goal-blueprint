# goal-spec

**Goal 前置设计 Skill（开发中）**

将不完整的产品构想经过开放研究、需求发现、产品取舍、架构设计、工程前瞻和独立审查，最终冻结为一份能交给 Goal 模式执行的权威 `GOAL_SPEC.md`。

**边界：**本项目只处理 Goal 启动前的规格质量，不负责执行 Goal、生成目标产品代码、故障接管或运行时授权强制执行。

## 当前阶段

- 架构与工作方法：候选方案，尚未完成验收。
- Skill 入口：尚未实现，不声称可以投入使用。
- `tests/replay/`：首批历史问题回放样本与评估协议，用来检验规格审查方法是否真正有用。

## 核心原则

- 研究可以自由发散，进入正式规格必须通过采纳决策。
- 重大业务语义、架构取舍、验收依据和授权边界在执行前明确。
- 预见未来不代表提前实现未来功能。
- 保护用户目标，不为完成任务清单而替代目标。
- 验证结果以实际证据为准：不得把已知答案的回顾性检查称为盲测。

详见 [回放实验说明](tests/replay/README.md)。

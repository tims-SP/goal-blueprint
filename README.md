# Goal Blueprint

**Goal 前置规格设计方法（开发中）**

将不完整的产品构想经过开放研究、需求发现、产品取舍、架构设计、工程前瞻和独立审查，最终冻结为一份能交给 Goal 模式执行的权威规格。

**边界：**本项目只处理 Goal 启动前的规格质量，不负责执行 Goal、生成目标产品代码、故障接管或运行时授权强制执行。

## 当前阶段

- 架构与工作方法：候选方案，尚未完成端到端验收。
- 需求发现与采纳：已有候选协议，尚未通过真实产品案例验证。
- Skill 入口：尚未实现，不声称可以投入使用。
- `tests/replay/`：规格审查缺陷回放样本与评估协议；不能替代完整规格设计流程的验证。

## 核心原则

- 研究可以自由发散，进入正式规格必须经过明确采纳决策。
- 用户未提及不代表没有需求；模型发现也不代表用户已经授权。
- 重大业务语义、架构取舍、验收依据和授权边界在执行前明确。
- 预见未来不代表提前实现未来功能。
- 保护用户目标，不为完成任务清单而替代目标。
- 验证结果以实际证据为准；不得把局部审查通过称为完整方法有效。
